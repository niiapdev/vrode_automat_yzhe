# bot2 — единая цепочка: аниме → субтитры → склейка → тиктоки

Всё новое лежит в этой папке. Оригиналы (`bot.py`, `local_bot.py`, `merger_local.py`,
`translator.py`, `config.py`, `skachka/`, `tik_tok-scripts/`) **не изменялись**.

## Что делает

Одно сообщение в ВК запускает полный цикл:

1. скачивает серии по параметрам как `skachka/batch_dl.py`
2. берёт дисклеймер `local_videos/previu/1.mp4` **копией** (оригинал не удаляется) как видео №1
3. скачанные серии нумерует с **2**, `3`, `4`… по возрастанию номера серии
4. по каждому видео: Whisper (GPU) → перевод на английский → субтитры + `logo.png`
5. склеивает всё в один файл в порядке нумерации
6. делает **4 тиктока** 1080×1920: сверху `tik_tok-scripts/1.png`, снизу `2.png`
   (каждый тикток — как один запуск `tik_tok-scripts/main.py`: 4 случайных 10-сек фрагмента ×2)
7. удаляет промежуточные файлы и присылает в ВК финальный отчёт

В ВК уходят только этапные сообщения (плюс «Принято» при постановке в очередь):

1. `📥 Скачивание: серии … | озвучка … | плеер … | 1080p`
2. `🎬 Скачано N серий. Обрабатываю: субтитры + склейка…`
3. `✅ ГОТОВО!` + имя итогового файла и папка с тиктоками

Подробности (какая серия распознаётся, какие фрагменты выбраны, каждый тикток)
пишутся только в консоль. Ошибка приходит одним сообщением.

## Формат сообщения

```
ссылка | серии | озвучка | плеер | качество
```

Примеры:

```
https://yummyani.org/anime/ya-vstrechayus-s-temnym-prizyvatelem | 1-6 | SHIZA Project | CVH | 1080
https://animego.org/anime/... | 5 | - | - | 720
cvh:1234 | все | - | - | 1080
https://yummyani.org/anime/... | ?
```

* `серии`: `5`, `1-12`, `все`, `-` (= все доступные). Если поле не указано — 1 серия.
* `озвучка` / `плеер`: `-` = выбрать автоматически (приоритет CVH, Aniboom, Kodik, Sibnet).
* `качество`: число, по умолчанию 1080.
* `| ?` — только показать доступные озвучки/плееры, ничего не качать.

Команды бота: `/help`, `/status`, `/cancel`.

## Запуск

```powershell
cd D:\for-move
.\.venv\Scripts\Activate.ps1
python bot2\bot2.py
```

Проверка без ВК (реальная ссылка, полный цикл):

```powershell
python bot2\bot2.py --selftest "https://yummyani.org/anime/... | 1 | SHIZA Project | CVH | 360"
```

Проверка без сети и без ВК (на готовой папке с `1.mp4`, `2.mp4`, …; файлы копируются):

```powershell
python bot2\bot2.py --selftest-local D:\путь\к\папке\с\видео
```

## Куда попадают файлы

```
bot2/
  local_out2/{Название} - серия 4.mp4          ← итоговое склеенное видео
  local_out2/{Название} - серии 1-15.mp4       ← если серий несколько
  tiktok_out2/{то же имя}/tiktok_01..04.mp4    ← 4 тиктока
  jobs2/<id>_<дата>/job.json                   ← отчёт по задаче (остальное удаляется)
  jobs2.sqlite3                                ← очередь задач
```

Имя итогового файла берётся из названия аниме и реально скачанных серий:
`серия 7`, `серии 1-15` (подряд) или `серии 1, 3, 5` (если часть серий не скачалась).
При совпадении имени добавляется ` (2)`, ` (3)` — готовые файлы не перезаписываются.
Для ссылок `cvh:<id>` осмысленного названия нет, поэтому будет `CVH 1234 - серия 1.mp4`.

Каталог `tik_tok-scripts/` используется только как источник `1.png` / `2.png`;
`tik_tok-scripts/output/` цепочкой bot2 не используется.

## Зависимости

```powershell
python -m pip install -r bot2\requirements-bot2.txt
```

Нужен `ffmpeg`/`ffprobe` в PATH и токен YummyAnime в `skachka/token.txt` (только чтение).

## Особенности окружения

* На этом ПК сертификат `api.vk.ru` подписан CA, которого нет в системном хранилище
  Windows, поэтому `bot2.py` подставляет бандл `certifi` (`SSL_CERT_FILE`). Без этого
  vkbottle падает с `CERTIFICATE_VERIFY_FAILED`.
* Если ВК-бот должен работать на CPU-ПК — см. `config2.py` / `translator2.py` в корне
  проекта и `requirements-cpu2.txt`.
